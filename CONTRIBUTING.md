# Contributing

Changes reach this repository as releases: each release is one commit made by
the maintainer.

- **Issues** are welcome: bugs, unclear docs, ideas.
- **Pull requests** are welcome too. The maintainer does not merge a pull request
  as it is. A change the maintainer accepts goes into the next release with credit
  to you (a `Co-authored-by:` line), and the pull request is closed with a link
  to that release.
- Do not include secrets, internal host names or personal data in an issue or a
  pull request: this repository is public.
