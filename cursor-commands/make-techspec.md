# TECHSPEC Command Router

Use skill: "sdlc-techspec-interview".

## Task
- Execute the skill end-to-end to convert PRD into an implementation-ready spec.
- Keep interview flow strict (one question at a time) and preserve requirement-to-decision traceability.
- Follow project rules from "AGENTS.md".

## Input
- "docs/prd.md" (or "PRD.md"), existing architecture context, and constraints.
- "AGENTS.md" project rules and priorities.

## Output
- Create or update "docs/techspec.md" (or "TECHSPEC.md" if project uses that naming).
- Include assumptions, risks, open questions, and ADR-candidate decisions required by "AGENTS.md" ADR policy.
