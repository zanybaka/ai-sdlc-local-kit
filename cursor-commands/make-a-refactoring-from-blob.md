# Refactoring from Blob Command Router

Use skill: "dev-refactoring-from-blob".

## Task
- Analyze a concatenated project snapshot and identify high-leverage refactoring zones.
- Produce ranked findings with evidence and safe incremental plans.

## Input
- Snapshot text produced from project files (for example via "./blob").
- Include code and documentation context where available.
- Follow detailed analysis protocol from "skills/dev-refactoring-from-blob/reference.md".

## Output
- Refactoring report with:
  - Rules and constraints extracted from docs
  - Refactorability index
  - Top-10 refactoring zones with evidence, risk, and tests
  - Coverage check and evidence gaps
