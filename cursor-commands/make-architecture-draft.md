# Architecture Draft Command Router

Use skill: "sdlc-architecture-draft".

## Task
- Execute the skill end-to-end for the current scope.
- Follow project rules from "AGENTS.md".

## Input
- "docs/prd.md" (or "PRD.md").
- "docs/techspec.md" (or "TECHSPEC.md").
- "AGENTS.md" project rules and priorities.

## Output
- Create or update "docs/architecture-draft.md".
- Include assumptions, risks, mitigations, open architecture questions, open information security questions, and a "Decision request" section with required approvals.
